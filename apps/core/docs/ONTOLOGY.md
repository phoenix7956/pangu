# Pangu 8 维向量本体论
**版本**: 0.5.1 · 2026-07-06

每卦 8 维向量是 Pangu 的"推理指纹", 由 6 个爻的属性聚合而成。

## 8 维构成
1. **强弱 (yin/yang 比例)**: 0=纯阴, 1=纯阳
2. **动静 (变爻比例)**: 0=全静, 1=全变
3. **位置 (爻位能量)**: 1-6 爻平均位置
4. **关系 (六亲复杂度)**: 0=无关系, 1=全相关
5. **时机 (应期长度)**: 0=快, 1=慢
6. **风险 (悔吝厉咎)**: 0=无险, 1=大凶
7. **增益 (元亨利贞)**: 0=无利, 1=大吉
8. **稳定 (卦序连贯性)**: 0=突变, 1=渐变

## 用法
```js
const hexagramVector = require('./64i/hexagram_vector');
const v = hexagramVector.compute(1, 3); // 卦 1, 第 3 爻
console.log(v); // [0.83, 0.17, 0.5, 0.6, 0.3, 0.2, 0.9, 0.7]
```
